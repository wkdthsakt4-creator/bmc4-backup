BMC4 Backup

BMC4 Backup은 운영자 본인의 Minecraft 서버 월드, 서버 구성 및 관리 프로그램을 Google Drive에 암호화하여 백업하고 복원을 검증하기 위한 개인용 앱입니다. 일반 사용자를 대상으로 가입이나 백업 서비스를 제공하지 않습니다.

앱이 하는 일

  • 서버가 정지된 상태에서 백업 파일과 무결성 검사 정보를 생성합니다.
  • rclone crypt로 파일 내용과 이름을 암호화하여 운영자의 Google Drive에 저장합니다.
  • 백업을 다시 다운로드하여 원본 서버와 분리된 임시 폴더에서 복원 및 파일 무결성을 검사합니다.

Google Drive 접근 권한

https://www.googleapis.com/auth/drive.file 범위를 사용합니다. 이 앱이 생성하거나 사용자가 이 앱에 사용을 허용한 Drive 파일을 백업·조회·다운로드·관리하는 용도입니다. Gmail 접근 권한은 요청하지 않습니다. Google 로그인 및 동의는 Google의 인증 화면에서 진행합니다.

현재 운영 상태

초기 설정 및 검증 단계입니다. 이 소개 페이지는 백업 실행 화면이 아니며, 방문자의 Google 계정 연결이나 파일 업로드를 받지 않습니다.

데이터 처리와 문의

보관·삭제·접근 철회에 대해서는 개인정보처리방침을 확인하세요. 일반 문의는 프로젝트 문의 게시판을 이용할 수 있습니다. 공개 게시판에는 비밀번호, 토큰, 백업 파일 또는 개인정보를 올리지 마세요.
